# KAPADIYA & SONS — identity

The brand name remains **KAPADIYA & SONS**. **Smit Kapadiya** is the founder.

The original eye mark uses an almond outline, a circular iris containing a K, and restrained solar rays. It draws on the supplied eye reference without reproducing its detailed illustration. The mark is drawn as SVG for crisp display, with a simplified version for the browser favicon.

## Assets

- `public/images/brand-eye.svg`: transparent gold symbol, viewBox 112 × 88.
- `public/favicon.svg`: simplified gold symbol on forest, viewBox 64 × 64.
- Header and footer wordmarks use live text for clarity and accessibility.

Do not stretch the symbol. Leave at least one iris radius of clear space around it. Use it on dark forest backgrounds; gold is not intended as small text on pale backgrounds. The site names the brand in the link’s accessible label and treats the adjacent symbol as decorative.

## Colour tokens

HEX codes are sRGB. Tokens live in `identity.css`.

| Token | HEX | Use |
|---|---|---|
| `--brand-forest` | `#121A14` | Dark background |
| `--brand-lime` | `#D4FF39` | Primary actions and focus highlights |
| `--brand-gold` | `#D7B781` | Eye mark, identity accents and dark-surface labels |
| `--brand-ivory` | `#F0F5E9` | Primary text on dark surfaces |
| `--brand-sage` | `#BDCBB5` | Secondary text on dark surfaces |
| `--brand-ink` | `#171B14` | Text on light and lime surfaces |

Colour supports text labels, icons and borders; it is never the only indication of a service category, action or selection.

## Typography and numbers

Manrope is the primary self-hosted sans serif. Georgia provides restrained editorial emphasis. Wordmarks use deliberate letter spacing rather than compressed or overlapping characters.

Package prices use `Intl.NumberFormat('en-IN')`, Indian rupees, comma grouping and no decimal fraction. Package cards explicitly state INR. Prices and counters use lining, tabular numerals. Telephone display is **+91 75758 07403**; machine-readable links remain `+917575807403` for telephone and `917575807403` for WhatsApp.

## Header and footer

The header provides the eye-and-wordmark lockup, four primary destinations and a project CTA. The footer provides a project invitation, navigation, telephone, email, WhatsApp, founder attribution, brand signature, privacy terms and back-to-top. The floating enquiry link is hidden and made inert when the footer or enquiry section is visible.

Canonical URL and sitemap use `https://www.kapadiya.tech/`. Existing service hash links remain available; they are views within the same page, not separate sitemap URLs.
